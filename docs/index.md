# Welcome!
{:.i18n .innerHTML-welcome}

## You're now on Anonymous_cat1's [**TW**i**L**ight Menu++ repository](https://github.com/Anonymous-cat1/twlmenu-extras/) for custom themes!
*(Visit the orignal [here](https://skins.ds-homebrew.com/)).*
{:.i18n .innerHTML-home-1}

- To see all available themes for whateer UI you're using, click it in on navbar.
{:.i18n .innerHTML-home-2}

- To make your own theme, there's a [wiki page on how to make Nintendo DSi / Nintendo 3DS theme](https://wiki.ds-homebrew.com/twilightmenu/custom-dsi-3ds-skins). For Original R4 and Wood themes, simply edit the images from an existing theme.
{:.i18n .innerHTML-home-3}

- Perhaps you've already made a theme? [create a pull request](https://github.com/anonymous-cat1/twlmenu-extras/pulls) on the GitHub repository!
{:.i18n .innerHTML-home-4}

> P.S. If you've have a 3DS or a 2DS, you can try scanning this QR code to add this repo. However, I can't promise it'll work.
